# Backend

Docelowo Supabase oraz PostgreSQL z rozszerzeniem PostGIS.

Zakres:
- schemat bazy i migracje,
- uwierzytelnianie,
- API i reguły dostępu,
- przechowywanie zdjęć i załączników,
- zgłoszenia i moderacja,
- synchronizacja danych mobilnych.

Nie umieszczaj w repozytorium kluczy API, haseł ani plików środowiskowych. Przykładowe konfiguracje powinny używać wyłącznie zmiennych demonstracyjnych.
