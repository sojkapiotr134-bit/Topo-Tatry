# Roadmapa TatryTopo

Roadmapa jest orientacyjna. Kolejne etapy powinny być zamykane kryteriami akceptacji, a nie samym upływem czasu.

## Etap 0 — przygotowanie projektu

- [x] Utworzenie repozytorium i podstawowej dokumentacji.
- [ ] Instalacja Git, Flutter SDK i Android Studio.
- [ ] Uruchomienie przykładowej aplikacji Flutter na emulatorze/telefonie.
- [ ] Ustalenie konwencji branchy, commitów i zgłoszeń.

## Etap 1 — fundamenty aplikacji

- [ ] Podstawy Dart i Flutter.
- [ ] Szkielet aplikacji i nawigacja ekranów.
- [ ] Konfiguracja MapLibre.
- [ ] Pierwsza mapa testowa.

## Etap 2 — proof of concept kartografii

- [ ] Wybór legalnych źródeł danych mapowych.
- [ ] Warstwice i cieniowanie rzeźby.
- [ ] Wczytywanie przykładowego GPX.
- [ ] Wyświetlanie pozycji GPS.
- [ ] Test wydajności i pamięci.
- [ ] Próba pobrania obszaru do offline.

## Etap 3 — model danych

- [ ] Schemat obiektów, przejść i wariantów.
- [ ] Model geometrii i trudności.
- [ ] Źródła i historia weryfikacji.
- [ ] Model ograniczeń prawnych i sezonowych.
- [ ] Walidacja danych.

## Etap 4 — karty obiektów i przejść

- [ ] Karty szczytów i przełęczy.
- [ ] Karty przejść i dróg.
- [ ] Opisy, parametry, warianty i zejścia.
- [ ] Zdjęcia topo i punkty charakterystyczne.
- [ ] Linkowanie obiektów z mapą.

## Etap 5 — nawigacja i offline

- [ ] Import i eksport GPX.
- [ ] Rejestracja śladu.
- [ ] Pobieranie map i danych offline.
- [ ] Synchronizacja danych.
- [ ] Obsługa błędów i testy terenowe.

## Etap 6 — backend i społeczność

- [ ] Logowanie i profile.

- [ ] Zgłaszanie błędów i aktualizacji.

- [ ] Logowanie redaktorów.

## Etap 8 — bezpieczeństwo, legalność i testy
