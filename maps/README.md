# Kartografia i dane mapowe

Ten katalog będzie zawierał dokumentację procesu przygotowania map, style, konfiguracje oraz skrypty pomocnicze.

## Planowane warstwy

- mapa bazowa,
- warstwice,
- numeryczny model terenu i hillshade,
- szczyty, przełęcze i inne obiekty,
- przebiegi przejść,
- punkty charakterystyczne.

## Zasady

- Weryfikować licencję, atrybucję i warunki redystrybucji każdego źródła.
- Nie wykorzystywać publicznych serwerów kafelków OpenStreetMap do masowego pobierania/offline bez zgodnych z regulaminem uprawnień.
- Zapisywać pochodzenie i datę aktualizacji danych.
- Oddzielać dane źródłowe od przetworzonych produktów kartograficznych.
