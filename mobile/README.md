# Aplikacja mobilna

Docelowa aplikacja Flutter/Dart na Androida i iOS.

Na tym etapie katalog zawiera dokumentację. Kod aplikacji zostanie wygenerowany po skonfigurowaniu środowiska i pierwszym teście MapLibre.

## Planowane moduły

- Mapa i warstwy.
- Wyszukiwanie obiektów.
- Karty szczytów, przełęczy i przejść.
- GPS i rejestracja śladu.
- Import/eksport GPX.
- Dane i mapy offline.
- Konto i synchronizacja.
